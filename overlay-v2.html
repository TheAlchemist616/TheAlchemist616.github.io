Zelda Layout

Preset layouts for the Zelda II frame image. Loads the matching background on top, sets up blank-channel stream panels in the big holes (slot1..slotN), and empty text panels in the banner strips (text1..textM — the 2-slot layout has 2, the 4-slot has 4, the 6-slot has none). Fill channels / text in afterwards, or push them in via chat with !load <preset> slot1 or !label text1 Alchemist.

Twitch Chat Commands

Not connected
Broadcaster + mods only:
!audio <channel> — switch audio
!mute — mute all streams
!sync — reload all streams
!layout <cols>x<rows> — e.g. 3x2
!add <channel> — add stream
!remove <channel> — remove stream
!change <old> <new> — swap streamer
!set <slot#> <new> — set slot (stream/url/text)
!text <text> — add text box
!settext <slot#|text<N>> <text> — update a text box (or !label text1 Alchemist)
!zoom <channel> <1-8>
!pan <channel> <x%> <y%>
!timer <category/room> — set racetime 1 (!timer off removes it)
!timer2 <category/room> — set racetime 2 (!timer2 off removes it)
!timer — force-refresh BOTH clocks (unstick the display)
!frame <url> — load frame image
!frame off — remove frame
!config <url/hash> — load full config
!reload — pull latest config from cloud
!sync — re-sync all stream players
!load <preset> [slot<N>|text<N>] — drop a preset; the slot/text name positions it
!presets — list saved preset names
!layer <n|next|prev> — bring a numbered layer forward
!zelda <2|4|6> — apply a Zelda frame layout (streams slot1..slotN plus text1..textM for the banner strips)
